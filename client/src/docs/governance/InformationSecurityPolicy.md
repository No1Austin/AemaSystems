# 1. Purpose

The purpose of this Information Security Policy is to establish the principles and controls used by AEMA Systems to protect company information, customer information, software, infrastructure, and business operations from unauthorized access, disclosure, alteration, destruction, or disruption.

Information security is fundamental to maintaining customer trust and supporting the long-term success of AEMA Systems.

---

This policy applies to:

• AEMA Systems

• All software developed by AEMA Systems

• AEMA AI

• TaskFlow

• AEMA Invest

• Company websites

• Cloud infrastructure

• Customer information

• Contractors

• Future employees

# 5. Access Control

Access to information shall be granted only where necessary for legitimate business purposes.

Users shall receive the minimum level of access required to perform their responsibilities.

Administrative access should be restricted whenever possible.

---

# 6. Authentication

Strong passwords shall be used.

Where available, multi-factor authentication should be enabled.

Shared accounts should be avoided.

Passwords should never be stored in plain text.

---

# 7. Data Protection

Reasonable safeguards shall be implemented to protect customer information.

Examples include:

HTTPS

Encryption where appropriate

Authentication

Access controls

Secure cloud infrastructure

Secure payment providers

---

# 8. Software Development

Security should be considered throughout software development.

Developers should:

Validate input

Protect APIs

Handle errors safely

Keep dependencies updated

Avoid exposing secrets

Review code before deployment

# 10. Security Incidents

Security incidents should be:

Reported

# 11. Backups
